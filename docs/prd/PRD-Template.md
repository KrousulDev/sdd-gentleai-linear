---

## 1. Problem Statement

**Objetivo:**  
Definir claramente el problema que se está resolviendo.

**Debe incluir:**
- Contexto actual del sistema o ecosistema
- Dolor del usuario (pain points concretos)
- Limitaciones del enfoque actual
- Por qué el problema es relevante ahora

**Formato sugerido:**
- Estado actual
- Problemas específicos
- Impacto (técnico, negocio, usuario)

---

## 2. Vision

**Objetivo:**  
Describir el estado ideal después de resolver el problema.

**Debe incluir:**
- Cómo se verá la solución final
- Qué cambia para el usuario
- Diferenciadores clave
- Before vs After (muy recomendado)

---

## 3. Target Users

**Objetivo:**  
Definir quién usa el producto.

**Debe incluir:**
- Usuarios primarios (core users)
- Usuarios secundarios
- Casos de uso principales por tipo de usuario

### Primary Users
- Tipo de usuario + necesidad

### Secondary Users
- Tipo de usuario + necesidad

---

## 4. User Experience (UX)

**Objetivo:**  
Definir el flujo de interacción del usuario.

**Debe incluir:**
- Entry points (cómo inicia el flujo)
- Steps del flujo principal
- Decisiones del usuario
- Estados del sistema

---

## 5. System / Feature Overview

**Objetivo:**  
Describir cómo funciona el sistema a alto nivel.

**Debe incluir:**
- Componentes principales
- Cómo interactúan
- Responsabilidades de cada módulo

---

## 6. Core Functionality

**Objetivo:**  
Describir las capacidades clave del sistema.

**Debe incluir:**
- Qué hace el sistema
- Inputs / outputs
- Validaciones
- Reglas de negocio

---

## 7. Technical Architecture

**Objetivo:**  
Explicar cómo se implementa el sistema.

**Debe incluir:**
- Componentes técnicos
- Interfaces (APIs, CLI, etc.)
- Flujos internos
- Diagramas

---

## 8. Data & Storage

**Objetivo:**  
Definir cómo se manejan los datos.

**Debe incluir:**
- Estructuras de datos
- Persistencia
- Formatos
- Ubicación de almacenamiento

---

## 9. Integrations

**Objetivo:**  
Definir integraciones con sistemas externos.

**Debe incluir:**
- APIs externas
- Servicios
- Dependencias
